# 跨文件符号索引

本索引只收被两个以上模块使用的函数、常量和字段。单文件私有函数见 `01`–`05` 各文件小节。行号是审查当日的定义位置。

## 配置与运行时值

| 符号 | 定义 | 读取方 | 备注 |
| --- | --- | --- | --- |
| `settings` | `config.py` `Settings` 67 | 几乎所有服务在启动时读默认值 | 热更新后不要再读它的密钥字段 |

| 字段 | 后端 | 前端类型 |
| --- | --- | --- |
| `dashscope_llm_api_key` | `Settings`、`RUNTIME_FIELDS` | `settingsService.ts`、`useSettingsStore.ts` |

| `dashscope_image_api_key` | 同上 | 同上 |
