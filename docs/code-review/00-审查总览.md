## 范围

手写后端在 `backend/app/`（约 69 个 Python 文件）。Blender 插件在 `backend/blender/addons/aicss_scene_builder/`（16 个 Python 文件）。前端手写代码在 `frontend/src/`，不含 `services/generated/`（约 50 个 `.ts` / `.tsx` 文件）。

`frontend/src/services/generated/` 与 `frontend/.schema-check-tmp/` 是 OpenAPI 生成物，按生成契约记录，不逐行当作业逻辑审查。`backend/test_outputs/`、`backend/bin/ffmpeg.exe`、`archify/`、`test/` 下的图片和剧本不纳入逻辑审查。

## 系统怎么串起来

```
浏览器 React
  use*Store / *Service.ts
    generatedClient (BASE = VITE_AICSS_BACKEND 或 http://localhost:8000)
      FastAPI main.py 挂载各 router
        endpoints_* 校验很少，直接调 services
          project_store / mesh_exporter / video_composer / model_manager
            磁盘 .workspace/projects、Blender、ffmpeg、llama-server、云 API
```

`backend/app/main.py` 在 `lifespan` 里调用 `settings_store.apply_overrides()`，再按 `model_mode` 决定是否 `ensure_server_running()`。路由前缀集中在 `main.py` 第 226–238 行。前端入口是 `frontend/src/main.tsx` → `App.tsx`，HTTP 基址在 `frontend/src/services/generatedClient.ts` 的 `DEFAULT_BACKEND`。

工作区根目录是 `Settings.workspace_dir`，默认 `backend/.workspace`（`config.py` 第 307 行）。项目子目录常量是 `project_store.WORKSPACE_DIR = settings.workspace_dir / "projects"`（`project_store.py` 第 60 行）。网格存储用同一个根：`project_store_mesh._WS_ROOT`。

## 严重级别

| 级别 | 含义 |
| --- | --- |
| 严重 | 未授权即可读、写、删本机文件，或接管进程与密钥 |
| 高 | 可造成密钥泄露、SSRF、任意媒体读取、资源耗尽 |
| 中 | 逻辑缺陷、竞态、信息泄露、密钥存放方式不当 |
| 低 | 可维护性、重复实现、边界不一致 |

## 结论（先看这些）

服务默认监听 `0.0.0.0:8000`（`config.py` 的 `host` / `port`），CORS 为 `allow_origins=["*"]`（`main.py` 第 217–223 行），全部路由没有认证依赖。能访问该端口的调用方可以列项目、读文件、删目录、改运行时设置、启停本机 `llama-server`、触发模型下载和 ffmpeg/Blender。

路径约束不统一。`endpoints_projects._validate_safe` 只保护产物文件名；`project_id` 在删除、合成、渲染下载里直接拼进 `Path`。`script_record.project_dir` 拒绝 `..`，`ProjectStore._project_dir` 不拒绝。合成接口把调用方给出的绝对路径交给 ffmpeg，并使用 concat demuxer 的 `-safe 0`。

密钥有三处落点：`~/.aicss/settings.json` 明文（`settings_store.py`）、浏览器 `localStorage` 键 `aicss_runtime_settings_v1`（`useSettingsStore.ts`）、以及三份测试脚本里的 DashScope 字面量密钥（见 `07` 文档 V-09，文档中不复写完整密钥）。

更完整的编号、调用链和改进顺序在 `07-漏洞与改进方案.md`。
