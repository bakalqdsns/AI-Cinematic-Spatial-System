# 开题报告目标与当前差距

## 目标成片

开题报告要的是一段 4–5 分钟、1080p 的 2.5D 纸雕空间动画。人物、场景和动作都按《纸间行》走：白衣少女、纸间城、教室、操场，纸雕质感统一。链路是剧本分镜、场景和人物三视图、GroundingDINO 加 SAM2 分割、Depth-Anything-V2 深度、遮挡补全、分层卡片、Blender 搭建和 Cycles 渲染、人物绿幕动作合成。镜头动起来时，近处偏移大、远处偏移小；人物挡住的东西被 LaMa 补全；同一个人物在不同分镜里长得一样。

## 当前结果

- 场景出图是纸雕操场，和剧本方向一致。
- 人物三视图还是白裙，不是《纸间行》的白衣少女设定；动作视频把绿幕画成了真实操场，抠出来的是带背景的卡片。
- 成片里人物仍是一块不透明卡片，两侧是分层场景，卡片和场景颜色、光照不一致。
- 当前只有 shot-1，只有 120 帧，离 4–5 分钟、1080p 很远。
- 分层已经按场景类、深度、近大远小落位，但人物和场景仍是两张互相独立的卡片。

## 反复迭代的顺序

1. 先修人物素材：剧本和人物提示词锁到《纸间行》的白衣少女，动作视频只出平整绿幕。观察人物卡片边缘和衣服上有没有绿边或洞。
2. 再修人物和场景的一致性：把抠好的人物放进场景，观察它是不是和场景颜色、光照、比例对得上。
3. 再修分层和透视：三视图观察远处面片有没有被透视压扁，近处有没有挡住该挡住的东西。
4. 最后扩成片：多个分镜连起来，观察人物是不是在不同分镜里长得一样，动作有没有断。

每一轮都从成片或三视图倒推问题，改完再渲。每轮把观察写进本文件。

## 第 1 轮：素材锁定

**改了什么。** `run_from_script.py` 的 `RAW_SCRIPT` 锁到《纸间行》操场一幕：白衣少女（16 岁，黑色长发，一身素白的连衣裙，纸雕质感）走过纸雕操场，场景和人物都写明 paper diorama / papercraft layered paper-cut。人物和场景的最终视觉提示词仍由接口补，不手写。

**MiniMax 绿幕参考帧为什么带出操场。** 倒推链路是：`run_from_script.py` 把人物三视图正面 `char_front.png` 作为 `start_image` 参考帧传给 `/api/aicss/v2/scripts/motion/generate`，ComfyUI 这条路再把它作为 MiniMax i2v 的首帧参考图。问题在参考帧本身：`character_generator.py` 的三视图提示词写死了 `white background`，和 `_comfy_character_prompt` 追加的绿幕后缀（平整 #00FF00）互相矛盾，模型听了前面的白底——`char_front.png` 的背景确实是白色不是绿幕。MiniMax 以白底参考帧为首帧锚点，绿幕后缀压不过参考帧；同时 `state.json` 里 shot-1 的 `action_prompt` 带着「外景。学校操场 - 白天」的场景文字，模型就把白底补成了真实操场。证据：`backend/.cache/comfy/minimax_dd3f1d26.mp4` 首帧（`_evidence_video_frame1.png`）里女孩站在带太阳、跑道、看台的真实操场上；抠出来的人物带背景，成片 `render_mid.png` 中间就是那块不透明人物卡片。

**处理。** 三视图提示词里的 `white background` 改成和绿幕后缀一致的 `solid bright green (#00FF00) chroma key background`（front/side/back 三处），绿幕后缀本身不动，动作视频提示词代码不动，分层不动。

**下一轮观察。** 重跑真链路时看三件事：新三视图背景是不是平整绿幕；动作视频背景是不是纯绿、有没有再把操场画回来；抠出的人物卡片边缘有没有绿边或洞。注意 `state.json` 缓存了旧剧本的解析、提示词、三视图和动作结果，重跑前先把它改名存档，否则旧素材会被原样跳过。
